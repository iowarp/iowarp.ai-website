The research question

## How does scientific data become useful context?

More throughput alone is not enough. Workflows need data placement, provenance, access, and reasoning to survive changes in format, scale, and computational environment. The CLIO platform grows from that systems question.

01 / Through lines

## Performance, context, and agency.

- 01 / Performance
  ### Move less. Move well.
  Memory and storage blending, tiered I/O, and dataflow-aware execution help scientific workloads use the resources they have.
- 02 / Context
  ### Keep the meaning.
  Data becomes more useful when metadata, structure, and computational state remain available to the next step.
- 03 / Agency
  ### Make tools usable.
  Scientific agents need grounded access to datasets, clusters, instruments, and evidence they can inspect.
